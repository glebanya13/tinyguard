# Tinyguard

Небольшая оригинальная 3D Tower Defense для Android в low-poly стиле.
Движок — **Godot 4.x**, язык — **GDScript**, рендерер — **Compatibility** (OpenGL ES 3).

> Статус: 0.4.0. Карта мира с 6 уровнями в 4 биомах (15–40 волн) и бесконечной осадой,
> 6 видов врагов (с летунами и щитовиками), 4 башни (с цепной молнией), онлайн-рекорды
> и облачное сохранение через Firebase (необязательно, см. `docs/FIREBASE.md`),
> звёзды и «Королевская казна» с постоянными улучшениями, рыцарь рубит любое дерево и
> бьёт врагов (удар и «Вихрь»), 3 типа башен за золото и дерево, кузница, боссы,
> пауза, ×2, музыка, иконка приложения и заставка для Android. Проверено в Godot 4.3
> на Linux (headless-тесты и программный OpenGL); на Mac и Android — ещё нет.

## Цель игрока

1. Пройти уровень → 1–3 звезды (3 — без потерь), следующий уровень открывается.
2. После победы открывается **бесконечная осада** уровня: рекорд волн даёт ещё звёзды
   (1 за каждые 10 волн, до 5 на уровень).
3. Звёзды тратятся в **Казне** на карте: стартовое золото и дерево, жизни замка, урон
   меча и башен, дерево за удар. Улучшения действуют во всех боях, их можно сбросить.

## Управление

| Действие | Клавиатура / мышь | Геймпад | Телефон |
|---|---|---|---|
| Идти | WASD или стрелки, клик по земле | левый стик, крестовина | экранный джойстик, тап по земле |
| Удар / рубить дерево | Пробел или J (стоя рядом — сам) | X | большая круглая кнопка (меч или дерево), стоя рядом — сам |
| «Вихрь» — удар по всем вокруг, раз в 12 с | Q или E | LB | кнопка над ударом |
| Рубить конкретное дерево | клик по дереву | — | тап по дереву |
| Приблизить / отдалить | колесо мыши | — | щипок двумя пальцами |
| Выбрать площадку | клик по ней или подойти | подойти | тап или подойти |
| Лучник (15 зол. + 10 дер.) | 1 или B | A | кнопка карты |
| Пушка (40 + 30) / Мороз (30 + 30) / Молния (50 + 40) | 2 или N / 3 или M / 4 или L | — | кнопки карты |
| Улучшить башню | U | Y | кнопка карты |
| Продать башню (70 %) | X | — | кнопка с монетой |
| Кузница: меч, ремонт замка | K | — | кнопка с молотом |
| Ускорение ×2 | F | — | кнопка «×1/×2» |
| Пауза | P | Start | кнопка «II» или «Назад» на Android |
| Снять выбор | Esc | B | кнопка ✕ |

Старт с нулём золота и дерева: дерево рубит рыцарь (любое дерево на поле), золото
дают убитые враги. Пока не построены первые башни, подсказка сверху и прыгающая
стрелка показывают следующий шаг. Волны идут сами; «▶▶» вызывает следующую раньше
за бонус, в отсчёте заранее видно, что идёт босс.

## Концепция

Игрок защищает маленькую крепость в центре компактной диорамы. По фиксированной
тропе идут волны врагов, игрок ставит башни на заранее отмеченные площадки,
тратит монеты и улучшает башни между волнами. Одна партия — 5–10 минут.

- Одна небольшая карта на экран, без прокрутки (масштаб — жестом, позже).
- Фиксированная изометрическая камера.
- Альбомная ориентация, управление касанием.
- Без сети, рекламы на старте и мультиплеера — всё работает офлайн.
- Яркий low-poly стиль: плоские цвета, без текстур, мягкий свет.

Подробности — в [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md).

## Запуск

### Требования

- Godot **4.3** или новее (стандартная сборка, не .NET).
- Для Android: Android Studio / SDK, JDK 17, export templates той же версии Godot.

### Десктоп (проверка в редакторе)

1. Установите Godot 4.3+ (macOS: `brew install --cask godot` или архив с godotengine.org).
2. Откройте Godot → **Import** → выберите `project.godot` в корне репозитория.
3. Дождитесь первого импорта (создастся папка `.godot/`, она в `.gitignore`).
   Без импорта игра не запустится: типы `class_name` (`Enemy`, `TowerData`…)
   регистрируются только при сканировании проекта редактором.
4. Нажмите **Run Project** (F5 / ⌘B). Герой стоит у замка; через 30 с из портала
   пойдут слаймы. Подведите героя к площадке и нажмите B, чтобы построить башню,
   U — чтобы улучшить. После победы или поражения кнопка «Играть заново»
   перезапускает уровень.

Из терминала:

```bash
godot --path . --editor            # открыть редактор
godot --headless --path . --import # импорт ресурсов и кэша class_name, затем выход
godot --path .                     # запустить игру (после импорта)
```

### Android

1. **Editor → Manage Export Templates** → скачать шаблоны.
2. **Editor Settings → Export → Android**: путь к Android SDK и Java SDK, debug keystore.
3. **Project → Export**: пресет «Android» уже лежит в `export_presets.cfg`
   (arm64 + armv7, полноэкранный режим, альбомная ориентация с поворотом по датчику).
   **Export Project** → `build/tinyguard.apk` (debug-подпись из настроек редактора).
4. Или подключите устройство с отладкой по USB → кнопка **Remote Deploy**.

На телефоне: джойстик слева, кнопка удара/рубки справа (иконка меняется: меч или
дерево), тап по земле — идти, тап по дереву — идти рубить, тап по площадке — меню
башен, щипок двумя пальцами — приблизить/отдалить. Стоя рядом с деревом или
слизнем, рыцарь бьёт сам.

Ключи подписи (`*.keystore`, `*.jks`) не коммитятся.

### Генераторы ассетов

```bash
blender -b --factory-startup --python assets/blender/build_all.py -- icons   # модели иконок
xvfb-run -a godot --path . --rendering-driver opengl3 --script res://tools/render_icons.gd     # ui/icons/*.png
xvfb-run -a godot --path . --rendering-driver opengl3 --script res://tools/render_app_icon.gd  # icon.png, ui/app/*
python3 tools/gen_sounds.py                                                    # звуки и музыка
```

### Тесты

```bash
tests/run_all.sh /path/to/godot     # headless: геймплей и проходимость на 3 уровнях, пауза, звёзды
python3 tools/balance_sim.py        # оценка баланса волн (жадный игрок)
gdlint scripts/*.gd tests/*.gd       # стиль (pip install "gdtoolkit==4.*")
```

### Проверка без Godot

```bash
python3 tools/validate_project.py
```

Скрипт проверяет обязательные файлы и каталоги, настройки рендерера и ориентации,
ссылки `res://`, объявленные ресурсы и `load_steps`, `NodePath` в сценах, пути `$...`
в скриптах корней сцен, уникальность `class_name`, `script_class` у `.tres` и
отступы табами. Это **не** замена запуску в движке.
