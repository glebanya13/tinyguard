# Game Design — Tinyguard

## Суть

Компактная Tower Defense на одном экране. Враги идут по фиксированной тропе от
точки спавна к крепости игрока. Игрок строит башни на отмеченных площадках.
Если у крепости закончились очки прочности — поражение; все волны отбиты — победа.

**Целевая сессия:** 5–10 минут на уровень. **Аудитория:** казуальные игроки,
короткие сессии с телефона.

## Основной цикл

```
Подготовка → Волна → Награда → (улучшение/строительство) → следующая волна
```

1. **Подготовка.** Перед волной игрок ставит/улучшает башни. Кнопка «Начать волну».
2. **Волна.** Враги выходят из спавна с интервалом и идут по тропе.
3. **Награда.** Монеты за каждого убитого врага + бонус за досрочный старт волны.
4. Конец уровня после последней волны.

## Карта

- Сетка ~12×8 клеток по 1 м, фиксированная тропа (заданная точками `Path3D`).
- **Площадки под башни** заданы дизайнером (4–8 на карту), строить можно только на них.
  Это проще для тача, чем свободная постановка, и не требует поиска пути.
- Крепость (база) — в конце тропы, имеет **20 очков прочности**.
  Враг, дошедший до базы, отнимает 1–3 очка и исчезает.

## Ресурсы

- **Монеты** — единственная валюта внутри уровня.
  Старт: 100. За врага: 5–15. Продажа башни возвращает 70% вложенного.
- Мета-прогрессии на первом этапе нет (возможно позже: звёзды за уровень).

## Башни (первый набор)

| Башня | Роль | Урон | Скорострельность | Радиус | Цена |
|---|---|---|---|---|---|
| **Лучник** | базовая, по одной цели | средний | высокая | средний | 50 |
| **Пушка** | урон по области | высокий | низкая | малый | 80 |
| **Мороз** | замедляет на 40% | низкий | средняя | средний | 70 |

- 3 уровня улучшения на башню (каждый — +урон/радиус, цена растёт).
- Приоритет цели по умолчанию: «первый на тропе» (ближе всех к базе).

## Враги (первый набор)

| Враг | HP | Скорость | Награда | Урон базе |
|---|---|---|---|---|
| **Слизень** | низкое | средняя | 5 | 1 |
| **Бегун** | очень низкое | высокая | 6 | 1 |
| **Танк** | высокое | низкая | 15 | 3 |

Все значения — стартовые для баланса, хранятся в `.tres`-ресурсах.

## Волны

- Уровень = 8–12 волн. Волна = список групп «тип врага × количество × интервал».
- Сложность растёт количеством и миксом врагов, а не только HP.
- Последняя волна — усиленная (больше танков).

## Управление (тач)

- **Тап по пустой площадке** → радиальное меню из 3 башен с ценами.
- **Тап по башне** → панель: улучшить / продать, показ радиуса.
- **Тап по пустому месту** → закрыть меню.
- Кнопки HUD: старт волны, пауза, скорость ×1/×2.
- Все интерактивные зоны ≥ 48 dp.

## HUD

Верхняя полоса: монеты, прочность базы, номер волны `3/10`.
Правый нижний угол: «Начать волну» / ×2. Левый верхний: пауза.

## Текущая реализация

| Тема | Сейчас в коде |
|---|---|
| Запуск | экран-карта острова (`level_select.tscn`): 3 уровня, следующий открывается после победы, пройденные отмечены звездой (`user://progress.cfg`) |
| Уровни | данные в `resources/levels.json`: тропа, замок, портал, площадки, рубимые деревья, старт героя, план волн. Поле 30 × 20 м, длинные змейки-тропы |
| 1. Зелёная долина | 15 волн, 8 площадок, 20 жизней, боссы на 10-й и 15-й |
| 2. Тёмная чаща | 25 волн, 10 площадок, 15 жизней, боссы на 10, 20, 25-й |
| 3. Королевский тракт | 40 волн, 14 площадок, 10 жизней, босс каждые 10 волн (на 20+ — по два) |
| Ресурсы | **золото** (за убитых врагов, бонус за досрочный вызов волны) и **дерево** (рубка деревьев героем). Старт: 0 / 0 |
| Герой | ходит (WASD / стрелки / стик / джойстик / тап по земле) в обход деревьев и камней (поиск пути по сетке); **удар** (Пробел / J / кнопка): 14 урона врагам в конусе 1.4 м, по дереву — +3 дерева. Стоя рядом со слизнем или деревом, бьёт сам |
| Деревья | **любое дерево** на поле (~50 на уровне); тап по дереву — рыцарь идёт рубить. Цель подсвечивается и обводится кольцом, кнопка удара показывает меч или дерево. 4 удара = 12 дерева, дерево падает, через 60 с вырастает заново |
| Подсказки | пока на поле меньше двух башен, сверху подсказка следующего шага: нарубить дров → добыть золото → построить башню |
| Телефон | джойстик, кнопка удара, щипок для зума, отступы под вырез экрана, без подсказок про клавиши; карта команд появляется только при выборе площадки |
| Башни | командная карта героя: Лучник (1/B) 15 зол. + 10 дер., Пушка (2/N) 40 + 30 — урон по площади, Мороз (3/M) 30 + 30 — замедление; 3 уровня, улучшение (U) за золото и дерево |
| Враги | слайм (22 HP), быстрый (12 HP, ×1.7 скорости, с 2–4-й волны), толстый в шлеме (75 HP, с 4–7-й), **король-босс** (520 HP, урон замку 8) |
| Волны | HP растёт на 8.5–11% за волну, врагов больше, интервал короче; первая через 30 с, дальше — через 25–30 с после конца предыдущей, кнопка «▶▶» вызывает волну раньше (+0.3 золота за секунду) |
| Отклик | баннер и рёв босса, всплывающие «+дерево», анимации удара, качание и падение дерева, вздрагивание врагов при попадании, звуки для всех башен |
| Конец игры | «Победа!» / «Поражение», кнопки «Играть заново» и «К карте» |

## Вне рамок первой версии

Мультиплеер, онлайн-таблицы, внутриигровые покупки, свободная постановка башен,
вращение камеры, процедурные карты, сюжет.
