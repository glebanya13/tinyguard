# Game Design — Bimbleguard

## Суть

Компактная Tower Defense. Враги идут по фиксированным тропам от 2–3 порталов с
разных сторон карты к крепости игрока (тропы сливаются у замка), камера следует
за героем. Игрок строит башни на отмеченных площадках.
Если у крепости закончились очки прочности — поражение; все волны отбиты — победа.

**Целевая сессия:** 10–25 минут на уровень. **Аудитория:** казуальные игроки,
короткие сессии с телефона.

## Основной цикл

```
Рубка дерева → бой со слизнями (золото) → постройка/улучшение башен → волна → …
```

Ресурсы: **золото** (враги, досрочный вызов волны, продажа, торговля с жителями) и
**дерево** (рубка, продажа). Расходы: башни, улучшения, кузница. Конец уровня — после последней
волны (победа) или когда у замка кончились жизни (поражение).

## Прогресс и цель

- **Звёзды:** до 3 за уровень кампании (3 — без потерь, 2 — не меньше половины жизней,
  1 — победа) и до 5 за бесконечную осаду (1 за каждые 10 пройденных волн). Всего 24.
- **Королевская казна** (карта мира): звёзды → постоянные улучшения, данные в
  `resources/perks/*.tres`:

| Улучшение | Эффект по уровням | Цена (★) |
|---|---|---|
| Казна | стартовое золото +15 / +30 / +50 | 1 / 1 / 2 |
| Лесопилка | стартовое дерево +15 / +30 / +50 | 1 / 1 / 2 |
| Крепкие стены | жизни замка +3 / +6 | 1 / 2 |
| Закалка | урон меча +20 % / +40 % | 1 / 2 |
| Меткие стрелки | урон башен +8 % / +16 % / +25 % | 2 / 2 / 3 |
| Острый топор | +1 дерево за удар | 2 |

  Всё вместе стоит 23 звезды; звёзды можно вернуть и перераспределить.
- **Бесконечная осада:** открывается после победы на уровне; волны не кончаются,
  боссы каждые 10 волн, рекорд сохраняется.
- **Экран итогов:** звёзды, новые звёзды и общий счёт, статистика боя (враги, золото,
  дерево, башни, время); при поражении — совет.

## Онлайн (необязательно)

Firebase (см. `docs/FIREBASE.md`): таблица рекордов бесконечной осады по каждому
уровню (топ-10, имя игрока), облачная копия прогресса. Без настроенного проекта игра
офлайн, кнопка «Рекорды» скрыта.

## Текущая реализация

| Тема | Сейчас в коде |
|---|---|
| Запуск | экран-карта острова (`level_select.tscn`): 3 уровня, следующий открывается после победы, пройденные отмечены звездой (`user://progress.cfg`) |
| Уровни | данные в `resources/levels.json`: тропы с порталами, замок, площадки, рубимые деревья, старт героя у замка, план волн. Поле 44 × 30 м; на 1-м уровне 2 портала, на остальных 3. Каждый вид врага ходит по тропам по очереди (1-й слайм — по первой, 2-й — по второй…; боссы тоже чередуются), поэтому оборону приходится делить; 13–15 площадок |
| 1. Зелёная долина | 15 волн, 8 площадок, 20 жизней, боссы на 10-й и 15-й |
| 2. Тёмная чаща | 25 волн, 10 площадок, 15 жизней, боссы на 10, 20, 25-й |
| 3. Королевский тракт | 40 волн, 14 площадок, 10 жизней, босс каждые 10 волн (с 30-й — по два) |
| 4. Снежный перевал (зима) | 30 волн, 14 площадок, 12 жизней, летуны с 4-й, щитовики с 7-й |
| 5. Осенняя роща (осень) | 35 волн, 14 площадок, 12 жизней, все враги с первых волн |
| 6. Песчаная крепость (пустыня) | 40 волн, 14 площадок, 10 жизней, финал: два короля с 30-й |
| Ресурсы | **золото** (за убитых врагов, бонус за досрочный вызов волны) и **дерево** (рубка деревьев героем). Старт: 0 / 0 |
| Герой | ходит (WASD / стрелки / стик / джойстик / тап по земле) в обход деревьев и камней (поиск пути по сетке); **удар** (Пробел / J / кнопка): 14 урона врагам в конусе 1.4 м, по дереву — +3 дерева. Стоя рядом со слизнем или деревом, бьёт сам |
| Деревья | **любое дерево** на поле (~50 на уровне); тап по дереву — рыцарь идёт рубить. Цель подсвечивается и обводится кольцом, кнопка удара показывает меч или дерево. 4 удара = 12 дерева, дерево падает, через 60 с вырастает заново |
| Подсказки | пока на поле меньше двух башен, сверху подсказка следующего шага: нарубить дров → добыть золото → построить башню |
| Телефон | джойстик, кнопка удара, щипок для зума, отступы под вырез экрана, без подсказок про клавиши; карта команд появляется только при выборе площадки |
| Башни | командная карта героя: Лучник (1/B) 15 зол. + 10 дер., Пушка (2/N) 40 + 30 — по площади, не бьёт летунов, Мороз (3/M) 30 + 30 — замедление, **Молния** (4/L) 50 + 40 — цепь по 3–5 врагам (каждый прыжок −20 % урона); 3 уровня, улучшение (U) за золото и дерево |
| Враги | слайм (22 HP), быстрый (12 HP, ×1.7 скорости), толстый в шлеме (75 HP), **летун** (16 HP, летит над тропой — пушка не достаёт), **щитовик** (55 HP, стрелы наносят 35 %), **король-босс** (520 HP, урон замку 5) |
| Волны | HP растёт на 8.5–11% за волну, врагов больше, интервал короче; первая через 30 с, дальше — через 25–30 с после конца предыдущей, вызвать волну раньше нельзя; время до волны показывает короткий баннер в начале уровня и при старте каждой волны |
| Отклик | баннер и рёв босса, всплывающие «+дерево», анимации удара, качание и падение дерева, вздрагивание врагов при попадании, звуки для всех башен |
| Конец игры | «Победа!» с 1–3 звёздами (3 — без потерь, 2 — не меньше половины жизней) / «Поражение», кнопки «Играть заново» и «К карте»; лучшие звёзды видны на карте |
| Продажа | башня продаётся за 70 % вложенного золота и дерева |
| Жители | 2 мирных жителя на уровне гуляют у замка (вдали от тропы и площадок, враги их не трогают). Рыцарь рядом (≤ 1.5 м) или тап по жителю — карта торговли: «продать 10 дерева» и «продать всё». Первая партия 10 дерева = 6 золота, каждая следующая дешевле в 0.93 раза (не ниже 2 золота за 10): цены партий 6, 6, 5, 5, 4, 4, 4, 4, 3 …; 100 дерева = 44 золота, 200 = 67. Курс сбрасывается в новом бою. Числа — `resources/villager_trade.tres` |
| Кузница | меч: урон 14 → 22 → 32 → 45 (40/30, 90/60, 160/100 золота/дерева); ремонт стен: +2 жизни за 25 дерева (не выше стартовых) |
| «Вихрь» | круговой удар радиусом 2.2 м, урон ×1.6, перезарядка 12 с |
| Пауза и скорость | пауза (кнопка, P, «Назад» на Android, автоматически при сворачивании), ×2; звук вкл/выкл сохраняется |
| Музыка | спокойная петля 38 с, синтезирована `tools/gen_sounds.py` |
| Подсказки | строка сверху + прыгающая стрелка над деревом / слизнем / площадкой, пока не построены 2 башни; в меню площадки роли башен |
| Баланс | проверяется `tools/balance_sim.py`: HP волн +15 % / +12 % / +9 % за волну (уровни 1/2/3), король отнимает 5 жизней, с 30-й волны боссов два |
