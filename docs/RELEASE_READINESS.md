# Готовность к первой публикации в Google Play

Дата оценки: 2026-10-14. Версия проекта: 0.4.0 (versionCode 4). Внешние требования сверены с
официальными страницами Google в этот день (ссылки в конце); перед отправкой на проверку
перечитайте их: правила меняются каждый год.

Обозначения: [x] готово · [ ] не сделано (разработка) · [ВЛАДЕЛЕЦ] нужно действие владельца
(аккаунт, юридические данные, URL, подписи).

## Вердикт

**К публикации в продакшн НЕ готово.** Игра играбельна и содержательна, код и политика данных в
хорошем состоянии, но есть блокеры, которые закрывает только владелец или отдельная проверка
сборки. Технических блокеров в коде, кроме AAB-сборки, нет; сильно желательна английская
локализация.

## Блокеры (без них Play не примет или отклонит)

1. [ВЛАДЕЛЕЦ] Публичный URL политики конфиденциальности: `GameInfo.PRIVACY_URL` пуст
   (`docs/PRIVACY_PUBLISH.md`). Нужен и в карточке Play Console. В `docs/PRIVACY.md` вписать
   e-mail и оператора.
2. [ВЛАДЕЛЕЦ] Публичный URL удаления аккаунта и данных без приложения: `GameInfo.DELETION_URL`
   (новая константа, пока пуста) и поле в форме Data safety. Приложение создаёт аккаунты
   (анонимный гость, e-mail), значит политика Play требует ОБА пути: в приложении (есть,
   «Профиль -> Удалить аккаунт») и веб-ссылку. Можно сделать страницей с инструкцией
   «напишите на SUPPORT_EMAIL с ID игрока, удалим в течение N дней» либо формой.
3. [ ] Сборка AAB: Play принимает только AAB. Сейчас пресет `use_gradle_build=false`, APK.
   Нужно: Project -> Install Android Build Template (шаблон 4.7.2), затем
   `gradle_build/use_gradle_build=true`, `gradle_build/export_format=1` (AAB), `target_sdk=36`
   (по умолчанию в 4.7, проверить в `android/build/config.gradle`). Не включено в этой ветке
   намеренно: без установленного шаблона и export templates headless-экспорт ломается, а
   собрать и проверить это здесь нельзя. См. `docs/ANDROID_BUILD.md`.
4. [ВЛАДЕЛЕЦ] Release keystore и Play App Signing (загрузочный ключ). Ключ хранить вне
   репозитория; пароли только в `export_credentials.cfg`/переменных окружения.
5. [ВЛАДЕЛЕЦ] Аккаунт разработчика Play (25 USD разово, верификация). Если он ЛИЧНЫЙ и создан
   после 13.11.2023: до продакшн-доступа обязательно закрытое тестирование минимум 12
   тестировщиков, подписанных непрерывно 14 дней, затем заявка на production access
   (актуально на 2026-10-14 по справке Google). Организационные аккаунты освобождены (по
   сторонним источникам; проверьте). Реалистично: минимум 2 недели до выхода.
6. [ВЛАДЕЛЕЦ] Заполнить в Console: Data safety (`docs/DATA_SAFETY.md`), Content rating (IARC),
   Target audience, App access, Ads declaration (нет рекламы), прочие декларации (нет).
7. [ГОТОВО, проверить владельцу] Графика карточки в `assets/store/`: иконка 512x512, feature graphic
   1024x500, 8 скриншотов 1920x1080 (список и команды: `docs/STORE_LISTING.md`). Загрузить в Console,
   оценить глазами; скриншоты русские (как интерфейс) и без подписей. Кнопки HUD и карты подняты до
   84 canvas px (48 dp), проверка `tools/measure_buttons.gd` на 2160x1080 и 2556x1179 без замечаний.

## Проверка проекта

### Экспорт (`export_presets.cfg`)

- [x] `com.bimbleguard.app`, `version/code=4`, `version/name=0.4.0` (совпадает с `config/version`).
  Перед КАЖДОЙ загрузкой увеличивать `version/code`.
- [x] Ориентация: сенсорная альбомная (`window/handheld/orientation=4`).
- [x] Разрешения: только INTERNET; `user_data_backup/allow=false`.
- [x] `firebase.cfg` включается в сборку, если лежит рядом; без него игра полностью офлайн.
- [ ] AAB/Gradle, `target_sdk`, release-подпись (блокеры 3-4).
- [ ] Фактическая сборка и запуск на устройстве НЕ проверены (нет export templates, см.
  `docs/ANDROID_BUILD.md`).

### UX и поведение (по коду и тестам)

- [x] Онбординг: экран ника, обучение, повтор из профиля («Пройти обучение заново»).
  Тесты `test_tutorial.gd`, `test_accounts.gd`.
- [x] Кнопка «Назад» Android: пауза в уровне (`main.gd`), закрытие панелей на карте, экран ника,
  выход на карте и на boot.
- [x] Пауза при звонке/сворачивании (`NOTIFICATION_APPLICATION_PAUSED/FOCUS_OUT`),
  `test_pause.gd`.
- [x] Звук вкл/выкл (карта, экран конца уровня), сохраняется в профиле.
- [x] Удаление аккаунта/данных, кнопка «Конфиденциальность» (открывает `PRIVACY_URL`, пока пуст
  показывает краткую сводку), ID игрока для поддержки.
- [x] Офлайн: игра без сети и без `firebase.cfg` работает полностью.
- [ ] Локализация: ВСЕ строки захардкожены по-русски, `tr()` и файлов переводов нет. Вне
  русскоязычных стран игра непонятна, оценки будут низкими. Не делалось в этой ветке: сквозная
  правка почти всех UI-файлов, конфликтует с параллельной работой. Рекомендация: отдельная
  задача (`translations/*.csv` + `tr()`), минимум RU+EN.
- [ ] Accessibility: нет настройки размера текста/контраста, TalkBack не поддержан (для 3D-игры
  не блокер). Размеры кнопок проверить на устройстве (цель >= 48 dp).
- [ ] Нет общего экрана «Настройки» (звук только на карте и конце уровня), выбора языка, показа
  версии, «Оценить игру».

### Ценность и удержание

Есть: 6 уровней с тремя звёздами, постоянные улучшения за звёзды, герой с джойстиком, жители и
торговля, бесконечная осада с онлайн-таблицей рекордов (серверная проверка по времени),
облачное сохранение, e-mail-аккаунт.

Нет: ежедневных заданий и наград, достижений, нового контента после 6 уровней кроме осады,
выбора сложности.
