# Art Guide — Tinyguard

Стиль: **уютная low-poly диорама**. Читаемость с телефона важнее детализации.

## Принципы

1. **Силуэт первичен.** Каждую башню и врага можно узнать по силуэту в 64 px.
2. **Плоские цвета, без текстур.** Цвет — через `albedo_color` материала
   или vertex colors. Без карт нормалей, без PBR-текстур.
3. **Мало полигонов, видимые грани.** Flat shading, фаски только на крупных формах.
4. **Ограниченная палитра** — см. ниже, новые цвета добавлять осознанно.

## Палитра (стартовая)

| Назначение | Цвет | Hex |
|---|---|---|
| Трава | зелёный | `#6BA85C` |
| Тропа | песочный | `#DBC285` |
| Небо / фон | светло-голубой | `#9ECBEB` |
| Игрок (база, акценты) | синий | `#4D85DB` |
| Враги | красный/оранжевый | `#D65247` |
| Камень (башни) | тёплый серый | `#C7C2B3` |
| Крыши / дерево | терракота | `#CC6640` |
| Площадки | серый | `#73737F` |
| Площадка выбрана | золотистый | `#FAD14D` (+ слабое свечение, кольцо `#FFE673`) |
| Площадка занята | тёмный графит | `#4D4F5C` |
| Снаряд | жёлтый (unshaded) | `#FFDB59` |
| Полоска HP | зелёный (unshaded) | `#6BD95C` |

Правило читаемости: **свои — синие/холодные, враги — красные/тёплые**.

## Бюджеты

| Объект | Треугольники | Материалы |
|---|---|---|
| Враг | ≤ 500 | 1–2 |
| Башня (уровень) | ≤ 1500 | 1–3 |
| Снаряд | ≤ 50 | 1 |
| Декор (дерево, камень) | ≤ 200 | 1 |
| Вся карта | ≤ 30 000 | общие |

Текстуры не используются; если понадобятся (UI, иконки) — ≤ 512×512.

## Масштаб и сетка

- 1 единица Godot = 1 м = 1 клетка карты.
- Враг ≈ 0.5–0.8 м высотой, башня ≈ 1.2–1.8 м, база ≈ 1.5–2 м.
- Пивот модели — в центре основания (на земле), «вперёд» — `-Z` в Godot.

## Освещение

- Один `DirectionalLight3D` сверху-сбоку (~55° наклон), тени включены.
- Ambient — цветной (`#D9E0FF`, энергия ~0.45), чтобы тени не были чёрными.
- Без post-processing, кроме возможного лёгкого тонмаппинга.

## Материалы

- `StandardMaterial3D`, `roughness` 0.8–1.0, `metallic` 0.
- Общие материалы хранятся в `assets/materials/*.tres` и переиспользуются.
- Для вариаций цвета врагов — разные материалы из палитры, не шейдеры.

## Пайплайн Blender → Godot

1. Исходник: `assets/blender/<name>.blend` (Blender 4.x).
2. Применить трансформации (Ctrl+A → All Transforms), пивот — в основании.
3. Flat shading; цвета — материалами из палитры с именами `mat_*`.
4. Экспорт **glTF 2.0 Binary (.glb)** в `assets/models/<name>.glb`:
   +Y Up, Apply Modifiers, без камер и источников света.
5. В Godot при необходимости заменить материалы на общие `.tres` из `assets/materials/`
   через настройки импорта.

Именование: `tower_archer_lv1.glb`, `enemy_slime.glb`, `prop_tree_a.glb`.

## Куда встанут модели (текущие заглушки)

Логика не зависит от мешей, поэтому модели заменяют только визуальные узлы.
Скрипты и корневые узлы сцен не трогать.

| Сцена | Узел-заглушка | Пивот / размер сейчас | Примечание |
|---|---|---|---|
| `scenes/tower.tscn` | `Body`, `Head` | основание в `y = 0`, высота ≈ 1.2 м | снаряд вылетает на `muzzle_height = 1.1` (`tower.gd`) |
| `scenes/enemy.tscn` | `Body` | основание на тропе, высота ≈ 0.4 м | `HealthBar` на 0.65 м — поднять, если модель выше; прицел — `AIM_HEIGHT = 0.25` |
| `scenes/projectile.tscn` | `Mesh` | центр в начале координат | ≤ 50 треугольников |
| `scenes/tower_slot.tscn` | `Pad`, `SelectionRing` | диск r = 0.45 м, верх на `y = 0.05` | `Pad` использует `material_override` для состояний — модель должна иметь одну поверхность или состояния надо перенести |
| `scenes/main.tscn` | `Level/Ground`, `PathA–C`, `Spawn`, `Base` | см. сцену | тропа для движения — `Level/EnemyPath`, не меши |

Враг поворачивается по ходу тропы (`rotation_mode = Y`): «вперёд» модели — `-Z`.

## Интерфейс

- Крупные округлые кнопки, контрастные иконки, минимум текста.
- Шрифт — один, без засечек, с поддержкой кириллицы (лицензия OFL).
- Цвета UI — из той же палитры.
