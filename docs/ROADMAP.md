# Roadmap — Tinyguard

Каждый этап заканчивается играбельной/запускаемой версией, проверенной в Godot.

## Этап 0 — Каркас ✅

- [x] Документация: README, CLAUDE.md, GDD, TDD, арт-гайд, роадмап
- [x] Структура каталогов, `.gitignore`, `.gitattributes`
- [x] `project.godot` (Compatibility, landscape, 1280×720)
- [x] Стартовая сцена из примитивов с изометрической камерой

## Этап 1 — Минимальный игровой цикл 🟡 (код написан, в Godot не проверен)

Объединяет бывшие этапы «Карта и движение» и «Башня и бой» плюс базовые волны и HUD.

- [x] `Path3D` по тропе тестовой карты (`Level/EnemyPath`)
- [x] `scenes/enemy.tscn` (`PathFollow3D`): HP, скорость, урон, полоска здоровья, удаление
- [x] Враг у базы отнимает жизни
- [x] `WaveConfig` + `resources/waves_level_01.tres`: 5 волн, рост числа врагов и HP
- [x] `WaveManager`: последовательный спавн, защита от двойного запуска волны
- [x] Башня-заглушка: ближайший враг в радиусе, периодический выстрел
- [x] `scenes/projectile.tscn`: снаряд наносит урон при попадании
- [x] `GameState`: 100 золота, 20 жизней, золото за убийство, поражение
- [x] HUD: волна, золото, жизни, кнопка «Начать волну», победа/поражение
- [x] Статические проверки: `validate_project.py`, gdparse, gdlint, gdformat
- [ ] **Проверка в Godot**: запуск, движение, стрельба, волны, победа и поражение
- [ ] Баланс на реальном запуске (сейчас подобран по Python-модели)
