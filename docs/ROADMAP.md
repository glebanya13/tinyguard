# Roadmap — Tinyguard

Каждый этап заканчивается играбельной/запускаемой версией, проверенной в Godot.

## Этап 0 — Каркас ✅ (текущий)

- [x] Документация: README, CLAUDE.md, GDD, TDD, арт-гайд, роадмап
- [x] Структура каталогов, `.gitignore`, `.gitattributes`
- [x] `project.godot` (Compatibility, landscape, 1280×720)
- [x] Стартовая сцена из примитивов с изометрической камерой
- [x] `tools/validate_project.py` — проверка без движка
- [ ] **Открыть проект в Godot и убедиться, что сцена запускается** (нужен Godot)

## Этап 1 — Карта и движение

- [ ] `Path3D` по тропе тестовой карты
- [ ] `enemy.tscn` на `PathFollow3D`, движение к базе
- [ ] Враг у базы исчезает и уменьшает прочность (пока print)

## Этап 2 — Башня и бой

- [ ] `TowerData`, `EnemyData` ресурсы
- [ ] Одна башня (лучник): радиус, выбор цели, выстрел
- [ ] HP врагов, смерть, награда

## Этап 3 — Экономика и строительство

- [ ] Autoload `GameState`: монеты, прочность, волна
- [ ] Площадки: тап → меню постройки
- [ ] Улучшение и продажа башни

## Этап 4 — Волны и HUD

- [ ] `WaveData`, `WaveSpawner`, кнопка «Начать волну»
- [ ] HUD: монеты, прочность, волна, пауза, ×2
- [ ] Экраны победы/поражения

## Этап 5 — Контент первого уровня

- [ ] 3 башни × 3 уровня, 3 типа врагов

- [ ] Low-poly модели из Blender вместо примитивов

## Этап 6 — Android
