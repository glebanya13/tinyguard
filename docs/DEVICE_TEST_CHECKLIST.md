## Подготовка (один раз на устройство)

1. Установить build (APK: `adb install -r build/bimbleguard-debug.apk`; из Play-теста — через ссылку теста).
2. Включить диагностику: Настройки -> версия внизу, **5 быстрых тапов** -> в бою слева сверху зелёный оверлей.
3. Записать строку устройства из оверлея: `GPU | ОЗУ | окно | dpi | Гц | safe l,t,r,b` и «tier (detected)».
4. Если есть кабель: `adb logcat -s godot` (инструкция: `docs/DEBUG_ANDROID.md`).

## Чек-лист на 15 минут (по порядку)

Отметьте результат: OK / замечание (скриншот или запись экрана).

**Запуск (2 мин)**
- [ ] Холодный старт до карты: время ____ с; заставка полноэкранная, без чёрных полос и без мигания.
- [ ] Альбомная ориентация, поворот на 180° (если есть автоповорот): игра не перезапускается.
- [ ] Первый запуск: экран ника, клавиатура не закрывает поле и кнопку «Далее»; форма e-mail (3 поля) — то же.
- [ ] Вырез/скругления: ни одна кнопка не под вырезом и не под жестовой панелью.

**Карта и меню (2 мин)**
- [ ] Все кнопки видны, не перекрывают друг друга (известно: «Лавка» и «Серия» могут перекрывать правый верх — карту переделывает другой агент).
- [ ] Лавка: превью 3D-модели видно (не чёрный квадрат), вращается; покупка за гемы без вылета.
- [ ] Настройки: «Качество графики» — 4 кнопки, выбор сохраняется после перезапуска; язык RU/EN переключается.
- [ ] Нажатие кнопок пальцем с первого раза (кнопки 48 dp).

**Бой (6 мин)**
- [ ] Уровень 1, затем уровень 6 (самый тяжёлый) до 10-й волны: FPS в оверлее ____ / ____ (цель >= 30 на бюджетном, 55–60 на остальных).
- [ ] Тени/эффекты есть на «высоком»; на «низком» их нет, игра играбельна.
- [ ] Джойстик + кнопка атаки **одновременно** (двумя пальцами): движение не прерывается.
- [ ] Строительство башни по тапу, меню башни, продажа, улучшение — без промахов.
- [ ] «Назад» в бою = пауза; ещё раз = продолжить; «Назад» на карте = закрытие панели/выход. На Android 16 тоже.
- [ ] Жест «домой» и возврат через 30 с: игра на паузе, время не «уехало», звук вернулся.
- [ ] Входящий звонок / уведомление / блокировка экрана во время боя: пауза, потом возврат без вылета.
- [ ] Температура корпуса через 10 мин боя: ____ (нагрев терпимый?), FPS не упал > 30 %.

**Сеть (3 мин)**
- [ ] Включить режим полёта: игра работает, рекорды/ежедневное в очереди без ошибок.
- [ ] Выключить: вход (анонимный), отправка рекорда, таблица загружается. Плохая сеть (слабый Wi-Fi) — не зависает дольше 10 с.
- [ ] Время устройства сдвинуть на +1 день и вернуть: ежедневное задание/серия не ломают игру (известный риск: результат дня может не принять сервер).

**Многооконность (2 мин, где есть)**
- [ ] Split-screen / оконный режим (Chromebook, планшет, складное): HUD перестраивается, кнопки доступны, бой продолжается.
- [ ] Складное: сложить/разложить во время боя.
- [ ] Chromebook: мышь — тап, колесо не ломает камеру; физическая клавиатура: WASD/Пробел работают.

## Как смотреть Google

- Pre-launch report: Play Console -> Test and release -> Testing -> Pre-launch report -> Overview / Details.
  Смотреть Stability (краши/ANR), Performance, скриншоты на разных экранах. Android 9+ только.
- Android vitals (после появления пользователей): Monitor and improve -> Android vitals; пороги: crash 1,09 %, ANR 0,47 % по
  приложению; по модели 8 %.
- Device catalog: Monitor and improve -> Reach and devices -> Device catalog -> «Export device list» (сколько
  устройств поддерживается/исключено для arm64-only).
- Firebase Test Lab (Spark: 10 виртуальных + 5 физических прогонов в день): запуск Robo на 5 разных физических
  устройствах для debug APK; живой Firebase-проект игры для этого не трогать.
