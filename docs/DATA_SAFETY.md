# Ответы для формы Data safety (Google Play)

Черновик по фактическому поведению (сверено с `docs/PRIVACY.md`, `docs/ACCOUNTS.md`,
`docs/FIREBASE.md`). Подаёт владелец в Play Console. При добавлении SDK или полей пересмотреть.
Не юридическая консультация.

## Общие вопросы

| Вопрос | Ответ |
|---|---|
| Собирает ли приложение пользовательские данные | Да (в онлайн-сборке с Firebase) |
| Передаются ли данные третьим сторонам | Нет. Google (Firebase) обрабатывает данные по поручению как service provider |
| Шифрование при передаче | Да (HTTPS) |
| Можно ли запросить удаление | Да: в приложении «Профиль -> Удалить аккаунт» и веб-ссылка `GameInfo.DELETION_URL` (TODO владельцу, обязательна) |
| Политика Families | Нет (рекомендуемая аудитория 13+) |
| Независимая проверка безопасности | Нет |

Реклама, аналитика, краш-отчёты, рекламный ID, геолокация, контакты, фото, платежи: не
используются и не собираются.

## Типы данных

| Категория Play | Тип | Собирается | Передаётся | Обязательно | Назначение |
|---|---|---|---|---|---|
| Personal info | Email address | Да, при создании аккаунта (и при привязке почты гостем) | Нет | Обязательно для аккаунта; режим «Играть без аккаунта» (гость) остаётся, поэтому для приложения в целом — необязательно | Управление аккаунтом (вход, подтверждение почты письмом, сброс пароля) |
| Personal info | Name (игровой ник) | Да | Нет (виден другим игрокам в таблице рекордов; указано в политике) | Обязательно онлайн | Функциональность приложения (рекорды), управление аккаунтом |
| Personal info | User IDs (анонимный Firebase uid) | Да | Нет | Обязательно онлайн | Функциональность, управление аккаунтом |
| App activity | Прогресс, звёзды, рекорды осады, звук, флаги обучения (по форме: Other user-generated content / In-app actions) | Да | Нет | Обязательно онлайн | Функциональность (синхронизация) |
| Остальные категории (Location, Contacts, Photos, Audio, Health, Financial, Device IDs, Diagnostics) | | Нет | | | |

Замечания:
- Пароль e-mail-аккаунта обрабатывает Firebase Authentication (хеш у Google); игра не хранит его
  и почту на устройстве. Firebase отправляет игроку письмо подтверждения почты и письмо сброса
  пароля.
- Форма «App access» в Play Console: «вход не требуется» верно, потому что «Играть без аккаунта»
  открывает всю игру без учётных данных; ревьюеру логин и пароль не нужны.
- Токен сессии лежит только на устройстве в зашифрованном файле.
- Без `firebase.cfg` (офлайн-сборка) приложение ничего не отправляет. Релиз для Play
  предполагается онлайн-сборкой с `firebase.cfg`.
- IP-адрес и технические данные запросов обрабатывает Google; упомянуты в политике.

## Удаление данных (вопросы формы)

- Удаление аккаунта: Да. Путь в приложении: Профиль -> «Удалить аккаунт» (без Firebase:
  «Удалить данные»). Веб-ссылка: TODO(владелец) = `GameInfo.DELETION_URL`.
- Удаляются: nicknames, publicProfiles, runs, nicknameTrace (если прошло 24 ч), users, saves,
  рекорды `leaderboards/*/scores/{uid}`, пользователь Auth.
- Сохраняется: инертная запись смены ника (без самого ника) может остаться до 24 ч по правилам
  Firestore (`docs/ACCOUNTS.md`); резервные копии Google по их срокам. Указано в политике.
- Частичное удаление без удаления аккаунта: не предусмотрено (кроме «Сменить имя»).
