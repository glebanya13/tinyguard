Bimbleguard — офлайн-игра. Онлайн-функции необязательны: без интернета и без
настроенного сервера игра работает полностью.

## Какие данные мы обрабатываем

| Данные | Зачем | Где хранится |
|---|---|---|
| Случайный анонимный идентификатор (Firebase Authentication, без почты и телефона) | отличать ваши рекорды и сохранение от чужих | серверы Google Firebase |
| Имя игрока (до 16 символов), которое вы вводите сами | показ в таблице рекордов | Firebase Firestore |
| Рекорд бесконечной осады (число волн) по уровню | таблица рекордов | Firebase Firestore |
| Файл прогресса (звёзды, улучшения, рекорды, настройки звука) — только если вы нажали «В облако» | перенос прогресса на другое устройство | Firebase Firestore |

Эти данные отправляются только при использовании онлайн-функций (новый рекорд осады,
облачное сохранение). Прогресс на устройстве хранится локально в файле приложения.

## Чего мы не делаем

- Нет рекламы, аналитики, трекеров и сторонних SDK.
- Не собираем почту, телефон, геолокацию, контакты, фото, рекламный идентификатор.
- Не продаём и не передаём данные третьим лицам. Хранение у Google Firebase —
  обработка по нашему поручению на условиях Google.
- Приложение запрашивает только разрешение INTERNET.

## Дети

Игра не нацелена на сбор данных детей. Не вводите в поле имени персональные данные.
