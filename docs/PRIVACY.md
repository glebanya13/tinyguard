# Политика конфиденциальности (черновик)

Черновик для владельца, **не юридическая консультация**. Перед публикацией проверьте его и
впишите контакты. Описывает поведение версии игры с этим репозиторием.

Контакт: _укажите e-mail поддержки_. Оператор: _укажите_.

## Коротко

Игра работает без интернета. Онлайн-функции (рекорды и облачное сохранение) включены только в
сборках с настроенным Firebase. Мы **не** используем рекламу, аналитику поведения, отслеживание,
геолокацию и не просим телефон, имя и фамилию. Единственное исключение, не связанное с аккаунтом:
**отчёты о сбоях** (Firebase Crashlytics, только в сборке для Android): если игра вылетела или
зависла, анонимный технический отчёт уходит разработчику, чтобы это исправить. Они **включены по
умолчанию и отключаются** в «Настройки → Отправлять отчёты о сбоях» (действует сразу). Основной способ входа — **аккаунт с e-mail и паролем**: он
нужен, чтобы прогресс не пропал при смене телефона или переустановке. Можно играть и **без
аккаунта** («Играть без аккаунта»): тогда e-mail не собирается, а прогресс привязан к этому
устройству. Для аккаунта мы обрабатываем e-mail и пароль (через Firebase Authentication) и
отправляем вам письмо для подтверждения почты; игра не блокируется, пока почта не подтверждена.

## Какие данные обрабатываются

| Данные | Зачем | Где хранятся |
|---|---|---|
| Случайный анонимный идентификатор (uid) | отличать игроков, привязать прогресс | Firebase Authentication, Firestore |
| Выбранный игровой ник (3–16 символов) | показывать в таблице рекордов, уникальность | Firestore (`publicProfiles`, `nicknames`, рекорды) |
| Прогресс: звёзды, открытые уровни, улучшения, рекорды осады | синхронизация между запусками и устройствами | Firestore (`users`) |
| Настройки (звук) и флаги «онбординг/туториал пройден» | то же | Firestore (`users`) |
| Результат Испытания дня: дата, волна, ник (или «Рыцарь»), серверное время | таблица дня | Firestore (`daily/{дата}/scores/{uid}`); удаляется вместе с аккаунтом (записи за сегодня и вчера; старше правила не допускают) |
| Открытые достижения (число-маска) и бонусные звёзды Испытания дня | синхронизация между устройствами | Firestore (`users`) |
| Баланс самоцветов (игровой валюты, за деньги не продаётся), ключи полученных наград, купленная косметика и выбранные скины, серия дней | синхронизация между устройствами | Firestore (`users`) |
| Время создания и обновления профиля | порядок слияния данных | Firestore |
| Время начала забега бесконечной осады и время последней смены ника (без самого ника) | проверка рекордов по времени, лимит смены ника раз в 24 ч | Firestore (`runs`, `nicknameTrace`) |
| Комната кооператива (только если вы играете вдвоём и в сборке задан `database_url`): uid, ник, код комнаты, выбранный уровень, служебные числа игры и ваши игровые команды (построить, улучшить и т. п.) | передать действия партнёру в реальном времени | Firebase Realtime Database (`rooms`, `user_rooms`) |
| **Отчёты о сбоях** (Firebase Crashlytics; включены по умолчанию, отключаются в настройках; только Android-сборка из Gradle): журнал сбоя и стек вызовов, а также «хлебные крошки» игры без личных данных (номер уровня, режим, сложность, номер волны, ступень качества графики, пик памяти), причина завершения прошлого запуска по данным Android (например, «убито системой из-за нехватки памяти»: причина, потребление памяти, важность процесса), модель устройства, производитель, версия Android, объём и состояние памяти, свободное место, ориентация, версия игры, **идентификатор установки Crashlytics** (Firebase Installation ID; случайный, не связан с вашим аккаунтом и почтой) | находить и исправлять вылеты и зависания, особенно на слабых телефонах | Firebase Crashlytics (Google); срок хранения у Google по умолчанию 90 дней _(проверьте в документации Firebase)_ |
| Токен обновления сессии | оставаться «в аккаунте» | только на устройстве, в зашифрованном файле |
| **E-mail и пароль** (только если вы создали аккаунт или привязали почту; гостю не нужны) | вход на другом устройстве, письмо с подтверждением почты, письмо для сброса пароля | Firebase Authentication. Пароль хранится у Google в виде хеша; игра не хранит ни пароль, ни почту на устройстве и не пишет их в Firestore и в логи. Статус «почта подтверждена» хранится на устройстве как флаг |
| Токен сессии и флаги «вошёл» | автоматически входить при каждом запуске, показывать прогресс без ожидания сети | только на устройстве: зашифрованный файл сессии и локальный файл сохранения (`progress.cfg` с резервной копией) |

Ник виден другим игрокам (таблица рекордов). **Не вводите в ник настоящее имя или контакты.**
Игровой ник не должен быть персональными данными; так как анонимный uid и ник вместе могут
идентифицировать игрока косвенно, мы считаем их персональными данными и даём их удалить.

Без `firebase.cfg` (офлайн-сборка) на сервер не отправляется **ничего**: данные остаются в
файле `progress.cfg` на устройстве.

## Комнаты кооператива

Нужны только для игры вдвоём (по умолчанию выключено; без `database_url` в `firebase.cfg`
ничего не отправляется). Комната содержит ваш uid, ник, номер уровня и поток игровых команд
с номерами тиков; партнёр по комнате видит ник и команды, посторонние читают только
информацию, нужную, чтобы войти по коду (ник хоста, уровень). Комната живёт до выхода
хоста или до окончания срока (`expiresAt`, 2 часа), хост удаляет её при выходе, пустая
комната закрывается через 10 минут. Без серверной очистки (план Spark) забытая комната
может храниться дольше срока, пока владелец не удалит её вручную; в ней нет ничего, кроме
перечисленного. **«Профиль → Удалить аккаунт» удаляет и вашу комнату, и вашу запись в
чужой комнате (`user_rooms`, `rooms`)**; для этого нужен интернет. Результаты кооператива
не попадают в таблицы рекордов и не меняют облачный прогресс.

## Чего нет

Реклама, аналитика поведения (Firebase Analytics и подобные), рекламные идентификаторы, геолокация, контакты, камера,
микрофон, платёжные данные и покупки за реальные деньги (самоцветы только зарабатываются в игре), данные детей сверх вышеперечисленного, передача данных
рекламным или брокерским сетям. Данные не продаются.

## Кто получает данные

Только Google (Firebase Authentication, Cloud Firestore, Firebase Crashlytics для отчётов о сбоях и, для кооператива, Realtime Database) как обработчик по нашему поручению;
письма подтверждения почты и сброса пароля отправляет Firebase. Мы не видим ваш пароль после его отправки в Firebase.
Google может обрабатывать технические данные запросов (например, IP-адрес) по своим правилам:
<https://firebase.google.com/support/privacy>. Дополнительных получателей нет.

## Права игрока и удаление

- **Удалить всё**: «Профиль → Удалить аккаунт». Удаляются ник и запись уникальности, публичный
  профиль, приватный профиль, облачное сохранение, рекорды на всех уровнях, время старта забега
  и пользователь в Firebase Authentication (вместе с привязанной почтой), затем данные на
  устройстве. Если вход был давно, игра попросит «Войти заново» и затем повторить удаление.
  Нужен интернет (облачную часть нельзя
  удалить офлайн); без Firebase стираются только локальные данные.
- **Выйти**: «Профиль → Выйти из аккаунта» (для аккаунта с почтой): данные на устройстве
  стираются, облачные остаются под вашей почтой. Забытый пароль: «Войти → Забыли пароль?».
  Гость выйти не может (его прогресс есть только на этом устройстве и в облаке под случайным uid);
  чтобы не потерять прогресс, создайте аккаунт — он привязывается к тому же uid, прогресс остаётся.
- **Отчёты о сбоях**: выключите «Настройки → Отправлять отчёты о сбоях» (сразу, без перезапуска;
  выбор запоминается). Уже отправленные отчёты не привязаны к аккаунту и нику; чтобы удалить их,
  напишите на контакт выше с идентификатором для поддержки из «Профиля»/настроек (если он
  показан) или временем и моделью телефона: владелец удалит отчёты вручную в консоли Firebase
  или они будут стёрты по сроку хранения (см. таблицу).
- **Исправить ник**: «Профиль → сменить имя» (не чаще раза в 24 часа).
- **Получить данные**: прогресс — это файл на вашем устройстве; облачную копию по запросу
  на контакт выше можно выгрузить по uid (его показывает «Профиль»).
- Если аккаунт удалён раньше чем через 24 часа после смены ника, остаётся документ
  `nicknameTrace/{uid}` (только uid и время смены, без ника): правила не дают удалить его
  раньше срока, а пользователя Auth уже нет. Он не содержит ника и бесполезен без аккаунта;
  владелец может удалить такие документы вручную.
- Копии в резервных системах Google удаляются по их внутренним срокам. Мы не храним
  собственных резервных копий.

## Срок хранения

Пока существует аккаунт. После удаления — см. выше. Неактивные анонимные аккаунты могут быть
удалены Google/нами по сроку неактивности _(укажите политику, если включите очистку)_.

## Дети

Игра не предназначена для сбора данных о детях. Анкета Google Play «Data safety» и
«Families» заполняется владельцем; если игра попадает в программу для детей, пересмотрите
этот документ.

## Безопасность

Передача по HTTPS. Доступ к данным в Firestore ограничен правилами: игрок читает и пишет только
свои документы, чужие данные недоступны (кроме публичного ника и рекордов). Ключ веб-API в
приложении — идентификатор проекта, не секрет. Токены и данные профиля не пишутся в логи игры.
Абсолютной защиты не бывает; рекорды проверяются только по минимально возможному времени
(см. `docs/ACCOUNTS.md`), не по ходу игры.

## Google Play: подсказки для анкеты Data safety (проверьте сами)

- Личная информация → адрес электронной почты: собирается при создании аккаунта (обязательно
  только для аккаунта; режим «без аккаунта» остаётся), нужен для управления аккаунтом, не
  передаётся третьим лицам, удаляется вместе с аккаунтом.
- Журналы сбоев (Crash logs), диагностика (Diagnostics), идентификаторы устройства (Device or other
  IDs: Firebase Installation ID): собирается; не передаётся третьим лицам; обязательно (в версии,
  где есть отключатель, он необязателен); цель — функциональность приложения и аналитика (исправление
  сбоев). Точные ответы: `docs/DATA_SAFETY.md`. Форму нужно перезаполнить перед выкладкой.
- Идентификаторы устройства/другие ID: анонимный uid — собирается, не передаётся третьим лицам,
  нужен для работы приложения, можно запросить удаление.
- Действия в приложении / игровой прогресс: собирается, не передаётся.
- Имя пользователя (ник): собирается, видно другим игрокам.
- Покупки в приложении: нет (виртуальная валюта зарабатывается игрой и не продаётся за реальные деньги; платёжные данные не собираются).
- Данные шифруются при передаче: да. Удаление по запросу: да (в приложении).
