# Передача работы (статус на 2026-10-14)

Ветка: `claude/ecstatic-noether-wkau2j`, версия 0.4.0. Правила — `CLAUDE.md`.

## Сделано (в ветке, тесты проходят)

- 6 уровней (лес, луг, болото, зима, осень, пустыня), карта мира с 6 точками, бесконечная осада.
- Волны по часам: каждая 30 с, перекрываются, пропуск и досрочный вызов убраны.
  Баннер один раз: «Первая волна через 30 секунд» / «Волна N! Следующая через 30 секунд» /
  «Последняя волна!» + звук `wave_boom.wav`.
- Враги: слизень, быстрый, танк, летучая мышь (только лучники/молния), щит, делящийся
  (+ мини), лекарь, каменный голем (броня), король-босс. Модели — `assets/blender/build_*.py`.
- Башни: лучник, пушка, мороз, молния (цепь); улучшения, продажа, кузница, перки казны.
- Жители, которым можно продать дерево (`scripts/villager*.gd`).
- Оптимизация: `EnemyCrowd` (все враги через MultiMesh), тени только у основания башен,
  компактный HUD для телефона. Draw calls в бою ~119 (было ~154).
- Firebase REST-модуль `scripts/online.gd` (анонимный вход, рекорды, облачное сохранение),
  `firestore.rules`, `docs/FIREBASE.md`. Живой проект Firebase **не создан и не проверен**.

1. **Большие карты и несколько дорожек.** Карты ~44×30, 2–3 пути врагов на уровень

2. **Аккаунты, профиль, онбординг, туториал.** Гостевой вход, версионированный профиль,

   правила Firestore, экран ника, интерактивный туториал на уровне 1, удаление аккаунта,
   `docs/ACCOUNTS.md`, `docs/PRIVACY.md`. Начаты только `scripts/nickname_rules.gd`,
   `scripts/game_info.gd`.
   Ограничения: никаких секретов/сервисных ключей в клиенте, не логировать токены и
   личные данные, без рекламы и аналитики, не утверждать, что вход работает, без теста
   на настроенном проекте.
