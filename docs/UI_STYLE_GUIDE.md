# UI style guide (theme v2)

Основа реализации `tools/make_ui_atlas.py`, `tools/make_ui_icons.py`, `ui/theme.tres`.

## Откуда взято

Владелец просил изучить референсы в браузере. Поиск картинок (Bing, DuckDuckGo, Google) в
рабочем окружении не отдаёт результатов (пустая выдача / капча), поэтому обзоров экранов
Clash Royale, Brawl Stars, Kingdom Rush, Bloons TD 6, Plants vs Zombies 2, Rush Royale и Hero Wars
в этой сессии получить не удалось, и ниже - **наблюдения по памяти об этих играх**, а не по
свежим скриншотам. Проверить глазами и поправить числа можно, положив скриншоты рядом с
`docs/screenshots/theme2_after_*`.

## Что общего у «дорогих» мобильных TD и карточных игр

| Тема | Наблюдение | Что сделано у нас |
|---|---|---|
| Слои панели | тёмная наружная кромка 3-4 px, яркая цветная рамка 4-6 px, светлая внутренняя линия, тело с градиентом и мягкой внутренней тенью, блик сверху | `panel()` в `make_ui_atlas.py`: кромка 4, рамка 4, тело-градиент, тень под рамкой, блик, «губа» 6 px снизу |
| Кнопки | толстый контур, верхний блик, нижняя «ступенька», при нажатии опускаются на 2-4 px, одна главная (жёлтая/зелёная), остальные тише | `button()`: контур 3, ступенька 8 (нажата 4), блик; золото только для главного |
| Заголовки | лента/табличка, выступающая из верхней кромки, крупный жирный шрифт с плотной обводкой и тенью | `RibbonLabel*` (лента-стиль Label), `TitleLabel` (обводка 6 + тень) |
| Шрифт | один тяжёлый дисплейный для заголовков, кнопок и цифр, читаемый для текста; обводка тёмная | Rubik 900/800 + Nunito 800; обводка 3 у кнопок и цифр, мелкий текст без обводки |
| Иконки | один стиль: толстый тёмный контур, объёмный градиент, блик сверху-слева, тень снизу; иконка занимает 60% кнопки | `make_ui_icons.py`: 30 иконок, контур 8 px на 256, блик, тень |
| Ресурсы HUD | капсула с круглым значком-монетой/деревом/сердцем слева, цифры жирные | `HudChip*`: бейдж нарисован в текстуре |
| Карточки | иконка-герой, название, статистика чипами, звёзды, рекорд, одна крупная кнопка | карточка уровня: эмблема биома, лента-название, звёзды 44 px, кубок и рекорд, сложность сегментами, «Играть» + «Игра на рекорд» одной ширины |
| Пространство | нет пустых плит: окно по содержимому, колонки по сетке 8 px | карточка и панели сжимаются по содержимому |
| Палитра | насыщенная, из логотипа: синий шлем, золото, зелень, розовый акцент | `NAVY`, `GOLD`, `BLUE`, `GREEN`, `RED` в скрипте атласа |

## Числа

- Сетка 8 px; радиусы 8 / 16 / 24; кромка 3 (кнопки, карточки) и 4 (панели).
- Шрифты: 14 (мелкая подпись), 16, 22 (кнопки, текст), 32 (заголовки), 48 (баннеры, итог).
- Цели нажатия >= 84 px (48 dp на 1080p); сегменты сложности 56 - исключение, как и раньше.
- Иконочные кнопки 84x84, иконка до 48 px.
- Безопасная зона: корень интерфейса сдвигается на `ScreenUtil.safe_margins`.
- Нижний левый угол: компас дорог и кнопка закрепления, над ними джойстик (`HudLayout`).
